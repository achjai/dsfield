Three starting points, all built around the same idea: see what is happening before you worry about optimisation.

/ 001 arrays

Bubble Sort

Compare two neighbours, swap them if they are out of order, and keep going until nothing else moves.

  • good first sort to learn
  • shows repeated passes clearly
  • easy to visualise on paper
/ 002 search

Binary Search

Cut the list in half, throw away the wrong half, and repeat. Fast, but only works on sorted data.

  • requires a sorted array
  • one decision per step
  • teaches you to trust the sort
/ 003 method

Step Tracing

arrays

Start here. Everything else gets easier after this.

Arrays are the friendliest structure to learn from, because the whole dataset is right there in front of you. There is no hidden pointer chasing, no recursion stack, just a row of values and a set of rules about how they move.

Type in any list you like, hit run, and follow the trace one comparison at a time.

trace 3 steps
input [9, 4, 7, 1, 3]
1

Compare 9 and 4. They are out of order, so swap them.

2

Move to the next pair and repeat. The largest value slowly floats to the end.

3

Once the first pass finishes, start again from the beginning with one less element to check.

Learn the pattern, not the answer.
